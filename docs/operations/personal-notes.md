# 随手记：发布与产品计划

## 本次交付

- Web 首页「随手记」与小程序「我的 → 随手记」。登录后保存私密记录，文字 1～5000 字、来源链接可选。
- 分页浏览、编辑、确认删除；输入失败不清空。跨端使用同一账号同步。
- 整理为常识会带入原内容和来源；不自动提交、不自动调用 AI、不公开原稿。原有投稿与人工审核流程不变。
- Web 记录页可创建个人令牌，只显示一次；数据库仅存 SHA-256 摘要。90 天有效、最多 5 个有效令牌，可撤销。
- 每人每天最多新建 100 条。API 令牌仅由 notes 控制器接受，不能用于登录、投稿或管理员接口。

## 部署

发布新镜像并重启应用；现有数据库初始化脚本会幂等创建 personal_notes、personal_note_tokens 表，不修改既有内容。
先备份数据库。小程序需重新构建、上传审核，单独更新服务器不会更新已发布小程序。
本地开发若不走镜像启动，需要先运行工程已有的数据库 initialize 命令。

## API 示例

只用 HTTPS。令牌不要放进 URL、源码仓库、公开截图或日志。

```sh
curl https://atlas.yarne.cc/api/notes \
  -H "Authorization: Bearer $NOTES_TOKEN" \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: idea-20261012-001' \
  --data '{"content":"今天想到一个值得核实的知识点","sourceUrl":""}'
```

同一条记录重试使用相同 Idempotency-Key；不同记录使用新键。相同键但内容不同返回错误。键只在当前用户内唯一。

- GET /api/notes?offset=0：每页 50 条，仅自己的记录。
- GET /api/notes/:id：读取自己的记录。
- PUT /api/notes/:id：整体更新 content/sourceUrl。
- DELETE /api/notes/:id：永久删除。
- GET/POST /api/notes/tokens、DELETE /api/notes/tokens/:id：只接受网页登录会话管理令牌。

## 增长与回访路线（尚未实现）

1. 先验证核心价值：让第一次访问无需注册即可浏览，想记录时再登录。衡量「浏览→保存第一条」转化、保存失败率、七日再次记录比例，先做匿名汇总设计，不采集私密正文。
2. 下一步做阅读详情「记下我的理解」、个人记录搜索与整理状态；避免用户积累记录后找不到。优先收集真实用户反馈再调整入口。
3. 提供一键安装的手机快捷指令模板和浏览器收藏工具，链接落地到内容本身，不要求先注册。令牌在设备端填写，绝不嵌入共享模板。
4. 内容增长：已审核常识做可分享卡片，清楚展示来源和作者；小程序走原生分享。不分享私密记录、不诱导转发或强制拉人。
5. 回访：用户主动订阅每周整理提醒，可关闭；只提醒未整理数量，不在通知泄露正文。先做「帮你用起来」，不做强制连续打卡。
6. AI 辅助单独迭代：明确征得发送私密文本到模型的同意，显示原文/建议对照、成本与缺失依据；用户确认后才能投稿，绝不编造来源或自动发布。

## 验收清单

两个不同账号互相读取/编辑/删除记录均不可越权；撤销、过期令牌失败；重复请求不新增；断网保留输入；Web/小程序同账号同步；原稿转投稿仍通过原审核；令牌不能登录管理员接口。
