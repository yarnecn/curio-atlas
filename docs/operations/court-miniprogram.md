# 芝麻开庭 · 独立微信小程序

2026-10-28 新增的首版源码。名称是工作名，尚未核验微信名称可用性或商标。

## 参与流程

产品名使用「芝麻开庭」，「这事你来判」作为分享邀请语。名称采用四个常用字，强调小事和模拟庭审；名称可注册性与微信内搜索结果仍待核验，不承诺搜索排名。

趣味来自开放的讨论流程，不预设搞笑结论。流程为阅读案情 → 独立选择 → 查看分布 → 自由发言 → 允许改票 → 原告记录结案。广场仅展示总参与人数；未投票者的详情接口不返回各选项票数，防止客户端直接泄露分布。原告、自述应诉者和审核员可跟进分布，结案后所有人可查看。该设计减少首次判断受多数意见影响，并不强制用户投票后才能发言。

参与者可选择辩护、提问、补充线索、提出结案方案、说明改判理由等角度，正文始终由用户自由撰写。角色可随时更换；真实经过与假设需要注明。系统只展示票数与领先情况，不生成戏谑判词，不把多数意见视作事实或正式判决。结案允许「保留不同意见」，不要求必须和好或达成搞笑赔偿。旧版本结案选项保留服务端兼容。

## 服务与数据

复用现有 NestJS API、MySQL、昵称账号与部署入口；新增 `/court` 模块，三个 `court_*` 表独立保存案件、投票和发言，不进入常识投稿、知识或推荐流程。已有数据库启动时通过 `infra/mysql/schema.sql` 的 `CREATE TABLE IF NOT EXISTS` 自动补表，无需修改原表。`infra/mysql/court.sql` 是相同建表语句的独立参考。

新案件先待审；owner/reviewer 在本小程序「审核席」通过后开庭。发言也先待审，作者可看到自己的待审发言。公众只看开庭和结案内容。账号一案一票，可改票；原告和已自述应诉的被告不能投票。被告身份为自述，未提供身份认证或独占绑定。结案由原告选固定选项，停止投票与评论，不代表被告同意。没有真实法律裁决或强制执行。

## 编译与发布

```powershell
pnpm install
pnpm --filter @knowledge-map/court-miniprogram typecheck
pnpm --filter @knowledge-map/court-miniprogram build
pnpm --filter @knowledge-map/database smoke:court
```

微信开发者工具导入 `apps/court-miniprogram`，默认读取 `dist-release`。将 `project.config.json` 的 `touristappid` 换为新小程序 AppID，并在公众平台配置 request 合法域名 `https://atlas.yarne.cc`。开发监听输出 `dist`，使用监听时相应修改 miniprogramRoot。

API 基址在 `src/api.ts`，默认 `https://atlas.yarne.cc/api`。后端按现有单镜像流程重新构建部署，路由与表才会出现在生产环境。开发构建不自动部署或上传小程序。新小程序有独立 Cookie 存储，需要重新登录，可使用原账号密码。

`smoke:court` 对已初始化的本地/测试 MySQL 验证建表、审核状态、投票去重与结案，所有测试写入在同一事务中回滚。连接沿用数据库包的 `DATABASE_URL`；不要指向生产数据库执行开发测试。

## 首版验收

1. 普通账号立案；广场不可见，自己的案卷显示待审。
2. 审核员登录审核席，通过案件；另一账号从分享路径打开案件。
3. 原告不可投票；其他账号改票不增加总票数。
4. 发言待审，通过后公开；被告应诉会移除本人的陪审票。
5. 原告结案后不能继续投票和发言；分享链接仍可阅读。
6. 验证加载失败、退出、空列表及分页。

## 发布前仍需完成

本轮 API 构建、小程序 TypeScript、ESLint、API 全部 34 项测试（法庭 12 项）及 Taro 微信生产构建均通过。新增验证覆盖广场与详情投票分布隐藏、结案后公开分布，以及作者查看自己案件的权限。使用桌面附带的 Node 24 运行；系统默认 Node 版本过旧，不适合此仓库。Windows 沙箱下 Vite/esbuild 的子进程创建受限，测试与 Taro 构建需在允许子进程的环境执行。

真实 MySQL 流程烟测、微信开发者工具与真机验证、独立 AppID 与平台审核。微信订阅提醒尚未实现，需要用户主动订阅、获批模板、服务端发送凭据与调度任务后才能提供。首版不包含图片证据上传、AI 判词、反诉、双方确认和提醒调度。

公共运营前还需确定隐私政策、用户内容投诉与下架处理方式；现阶段提供发布前人工审核，不应描述为已具备完整社区运营系统。
