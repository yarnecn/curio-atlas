# 候选精华与正式常识内容规范

## 候选精华模板

候选内容必须直接陈述结论，不以提问、求助或开放讨论的形式发布：

1. 一句话结论；
2. 为什么有用；
3. 适用条件、地域、时间或例外；
4. 来源链接，或明确标记为个人经验；
5. 所属话题和时效等级；
6. AI 生成或改写声明。

原始投稿不可覆盖。AI 可以生成压缩稿和风险提示，但展示前必须保存原稿、改写稿、模型版本、提示词版本和差异。

## 正式常识模板

每个正式知识节点必须回答：

1. 一句话解释；
2. 为什么值得知道；
3. 核心事实；
4. 背后的原理或背景；
5. 一个现实例子；
6. 适用边界与常见误解；
7. 前置和后续知识；
8. 2—5 道自测题；
9. 来源、发布日期、访问日期和复核日期。

## 事实与表述

- 可验证事实与分析、预测、立场和个人经验分开标记；
- 重要事实使用 claim 绑定具体来源和证据位置；
- 不使用“众所周知”“有研究表明”等不可追溯表述；
- 时间敏感内容写明有效期或下一次复核日期；
- 首次出现的术语用普通语言解释；
- 引用只保留说明问题所需的片段，不复制未授权全文；
- AI 优化必须保留原意，不能补写原稿和来源没有支持的事实；
- 标题避免夸大、绝对化、煽动性和伪权威表达。

## 生命周期

候选精华：

```text
submitted → automated_screening → trial
          → expanded_trial → queued_for_review
          → merged / rejected / withdrawn
```

正式常识：

```text
draft → pending_review → approved → published → superseded / archived
```

候选内容从来不直接转成 `published`，而是创建或更新一个正式常识草稿。每次正式内容修改都创建不可变版本。发布必须有人类审核者和审计记录。

## 来源优先级

优先使用法律政策原文、政府与统计部门、国际组织、大学科研机构、开放教材和已授权来源。媒体可用于发现线索，是否保存或公开正文取决于许可。

事实本身与他人受著作权保护的具体表达必须区分。对第三方材料默认只保存必要元数据、内容指纹和审核所需证据，不因“AI 改写”就视为自动取得使用权。

## 发布检查

- 标题、摘要、领域、类型、难度、适用边界和时效等级完整；
- 每个核心事实有可访问且真正支持结论的来源；
- 关系方向正确，前置知识不过度跳跃；
- 自测题能验证理解，不只考孤立记忆；
- 原始投稿、AI 改写和人工修订均可追溯；
- AI 生成合成内容已按适用规则标识；
- 无侵权全文、敏感个人信息或无法解释的相似表达；
- 复核日期与内容稳定性匹配；
- 高风险主题经过对应领域的加强审核。

## 纠错与撤回

用户通过私有表单提交“事实错误、来源失效、过期、侵权、隐私、安全风险或其他”原因。纠错不会形成公开评论。严重问题可以先下架当前版本，再由审核者发布修订版；所有动作保留原因和审计记录。
