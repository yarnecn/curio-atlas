# V1 内容生产计划

## 数量边界

V1 先完成 165 条稳定常识。采用“广度优先”：先让读者能在主要常识领域之间随意浏览，再逐步加深单一领域。

| 一级领域 | 稳定常识目标 |
| --- | ---: |
| 地理 | 20 |
| 历史与文明 | 20 |
| 政治法律与社会制度 | 15 |
| 经济金融 | 15 |
| 数学统计与逻辑 | 12 |
| 物理化学生物 | 18 |
| 健康与生活风险 | 15 |
| 计算机与数字安全 | 12 |
| 工程与基础设施 | 10 |
| 语言表达与沟通 | 10 |
| 文化艺术与日常生活 | 10 |
| 时事背景与世界格局 | 8 |

12 个一级领域下共有 48 个细分话题。每条内容由系统或编辑流程在入审核台前完成归类，站长审核内容，不重复做分类劳动。另保留 20 个现实热点背景名额；热点内容按时效更新，不计入稳定常识完成率。机器可读的唯一完整目录在 `content/v1/catalog.json`。

## 内容生产顺序

每批 10—20 条，按照以下顺序处理：

1. 从目录中选择尚未覆盖的条目；
2. 只从白名单权威来源抓取事实线索、标题、地址和更新时间；
3. AI 重新组织成“一句话说明、为什么值得知道、边界或常见误解”三个短段落；
4. 校验重复、长度、绝对化表述、来源缺失和时效；
5. 作为内部候选进入审核台；
6. 站长批准或修改后才发布，未通过内容不出现在首页。

抓取不保存或复制第三方全文。事实本身可重新表述，来源的具体表达、图片和图表没有许可时不复制。

## 首批来源池

- 中国公共事实：中央和地方政府部门、国家统计局及相应专业机构；
- 国际公共事实：联合国及其专门机构、世界银行、IMF 等原始资料；
- 自然科学与工程：科研机构、标准机构、大学公开教育资料和政府专业机构；
- 健康与安全：国家卫生健康部门、WHO 等权威健康机构，使用更严格的时效和风险复核；
- 文化与历史：博物馆、图书馆、档案馆、教育与文化机构的原始说明。

首页不把“来源池主页”当成有效证据。正式候选必须链接到支持该结论的具体页面或文件。

## 当前进度

- 机器目录：165 / 165 个题目已确定；
- 分类目录：12 个一级领域、48 个细分话题、165 / 165 个稳定题目已确定；
- 当前内容：MySQL 空库初始化 20 篇 starter，尚未作为 V1 正式编辑成果验收；
- 待生产内容：目录还剩 145 个题目，需要从具体来源页重新抓取、整理并进入 `/admin/review`；
- 后续批次：优先补齐当前没有正式内容的领域，再逐步加深已有领域。

运行 `npm run content:status` 可以查看每个细分话题的“已发布 / 待审核 / V1 目标”。审核台顶部按 12 个一级领域汇总，筛选器再按 48 个细分话题定位内容。

## 验收标准

- 读者不需要搜索就能从正文获得完整答案；
- 单条通常 1—3 分钟读完，正文 60—900 个中文字符；
- 至少两个短段落，并写清必要边界；
- 每个核心事实有直接来源；
- 同一知识不换标题重复发布；
- 历史争议、现实政策和统计口径明确时间与证据边界；
- V1 完成不是目录凑满，而是 165 条全部经站长审核通过。
