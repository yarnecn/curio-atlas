# 来源与人工审核

来源是可选的判断依据，不是投稿或正式收录的硬性门槛。此规则替代此前“正式常识必须有关联来源”的要求。

- Web、小程序、投稿 API 和内部编辑入口允许不填来源；填写时仍需有效网址。
- 个人经验标记作为审核参考，不因该标记或缺少来源自动禁止发布。
- 人工初审、正式审核、权限和内容长度等校验保持不变，不自动通过。
- 发布、合并无来源内容不创建 sources、source 内容块或带来源的 claims；审核决定仍按原流程留痕。
- 无来源的已发布版本允许按原有权限和内容校验回滚，不用来源数量代替审核。
- 审核台展示缺少来源的提示，但由审核人决定通过、拒绝或暂缓。
- 抓取订阅仍需抓取网址；它是任务目标，不属于可选的投稿参考来源。
