# 常识地图产品愿景与闭环

- 版本：1.2
- 日期：2026-09-03
- 状态：产品负责人方向校准后的最高优先级产品基线

## 一句话定位

常识地图是一套**可以随手翻的主动推荐型常识百科**：用户不必先有问题，也不必知道搜索词，打开后就能看到简短、可信、有趣、能继续延伸的常识；感兴趣时再沿话题、关系或外部来源深入。

搜索是兜底工具，不是首页中心；学习系统是增强能力，不是使用产品的前提；个人知识库是用户沉淀结果，不是产品本体。

## 两种都成立的产品结果

1. 没有外部用户时，它仍是站长自己的常识百科：系统持续发现知识缺口和来源变化，AI 生成候选与更新建议，站长只处理批量审核。
2. 有外部用户时，它在相同内容内核上增加兴趣推荐、反馈和可选账号能力，并在出现真实留存后验证变现。

产品不能依赖用户投稿才能增长，也不能依赖用户主动搜索才能产生价值。

## 五个必须闭环的循环

```text
打开即看 → 换一条 / 继续看 → 发现兴趣 → 沿关系深入 → 下次更合适
    ↑                                                   ↓
    └──────────── 多样性、已读和质量反馈持续调整 ──────┘

知识范围 → 发现缺口 → 白名单来源取证 → AI 候选 → 人工审核 → 正式发布
    ↑                                                        ↓
    └──────── 来源更新、过期复核、纠错和覆盖率扫描 ──────────┘

运行指标 → AI 发现问题 → 提出小改动 → 自动测试 → 人工批准 → 发布/回滚
```

### 浏览闭环

- 首页首屏直接出现一条可读常识，不用先选分类、注册或搜索；
- 每条内容控制在约 30—90 秒可理解，提供“换一条”和 1—3 个自然延伸方向；
- 推荐同时考虑兴趣、知识多样性、已读去重、难度、质量、时效和领域覆盖，不能只追热点；
- 一次会话可以无限继续，但每若干条主动换领域，避免形成单一信息茧房；
- “有用 / 没用”评价内容价值，跳过和继续阅读只做推荐信号，不公开展示为社交数据。

### 内容供给闭环

- 先维护一张跨领域“常识覆盖地图”，系统从空白、薄弱、过期和关联断点中生成任务；
- 官方资料、开放数据、科研教育机构和已授权来源按白名单定时检查；
- AI 负责去重、提炼、拆分 claim、发现冲突、补充边界、生成关系和审核摘要；
- AI 产物永远先进入候选或待审核版本，不能成为公开事实；
- 站长看到的是每日或每周批量审核包，而不是逐条从零编辑；
- 发布后自动安排复核日期，来源变化、死链和用户纠错会再次进入审核队列。

### 质量闭环

- 有用率判断“是否值得保留和继续展示”，来源与审核判断“是否可信”；
- 内容曝光必须保留最低探索比例，不能因为早期票少就永久埋没；
- 对“太基础、难理解、缺少边界、来源失效”等内部原因分别统计，不开放评论区；
- 低质量、重复、过期或长期无人完成阅读的节点进入重写、合并、降级或归档建议；
- 每次 AI、规则和模板变化先跑固定评测，再进入少量任务。

### 运营闭环

- AI 每日检查来源、队列、覆盖缺口、内容表现、错误、性能和成本；
- 低风险动作可自动重试和生成草稿，高风险内容、正式发布、生产变更和付费动作必须人工批准；
- 每项建议包含证据、预期收益、风险、验证指标和回滚方式；
- 即使没有用户数据，覆盖率、来源新鲜度、复核到期和内容一致性仍能驱动迭代。

### 商业闭环

- 第一阶段只验证“有人愿意持续随手看”，不为广告系统增加复杂度；
- 达到连续留存和自然传播门槛后，先测试不损害基础百科体验的付费价值；
- 收入优先投入内容审核、来源授权、服务器和高价值专题，形成质量再投资。

## 核心界面

### 首页：打开就能看

首版首页按下面的优先级组织：

1. `随便看看`：跨领域、高质量、未读优先的常识卡；
2. `今天值得知道`：少量与当前现实有关、但仍以背景常识为主的内容；
3. `你可能感兴趣`：访客可直接勾选兴趣，登录不是前提；
4. `沿着这个继续`：当前节点的前因、后果、对比、组成和现实例子；
5. `知识领域`：当用户想主动选择方向时再进入目录；
6. 搜索：保留在顶部或菜单中作为辅助入口，不占据首屏中心。

### 常识卡

每张卡只解决一个认知增量：

- 一句话结论；
- 为什么值得知道；
- 一个例子、反例或常见误解；
- 必要的适用边界和时效；
- 来源与复核时间；
- `换一条`、`继续了解`、`收藏`、`有用 / 没用`。

长内容可以存在，但默认先给短卡。用户对某一项产生兴趣后，再进入完整节点、关系路径或外部来源。

### 简单但不乏味

- 主要手势或按钮始终只有“换一条”和“继续了解”，不用先学会复杂导航；
- 内容形态轮换使用事实卡、对比卡、时间线卡、地图卡、数字卡、误区卡和现实背景卡；
- 适量使用“先猜一下”“展开原因”和关系路径，但答题不是强制步骤；
- 显示“今天遇见了几条新常识”和领域分布，不使用强迫签到、惩罚断签或刷榜；
- 连续出现相似主题、相同难度或相同卡片形态时主动打散；
- 动效只用于解释关系和提供反馈，低性能设备和小程序弱网环境可以降级。

## 内容范围与“大全”的定义

“大全”表示覆盖面持续完整，不表示首日堆满所有词条。内容按先广后深构建：先让用户在主要生活与通识领域都能遇到可靠的基础节点，再逐步增加专题深度。

首层覆盖至少包括：世界与中国地理、历史与文明、社会制度与法律、经济金融、数学统计与逻辑、物理化学生物、健康与生活风险、计算机与数字安全、工程与基础设施、语言表达与沟通、文化艺术与日常生活、现实事件背景。

内容分三级管理：

1. 核心骨架：约 1,000 个大多数成年人值得知道的节点；
2. 实用扩展：逐步增长到约 3,000 个能解释生活和现实的节点；
3. 兴趣专题：在质量与维护能力允许时扩展到 5,000 个以上。

数量不是发布指标。节点必须通过“值得知道、来源可靠、表述清楚、边界完整、可维护”五项门槛；孤立猎奇、无法核验或只能制造情绪的内容不用于凑规模。

## 账号与真实身份

身份按动作逐级增加，不把注册放在价值之前：

| 动作 | 账号要求 | 公开身份 |
|---|---|---|
| 浏览、换一条、选择临时兴趣 | 无需账号 | 无 |
| 本机保存已读和兴趣 | 无需账号，先存在设备 | 无 |
| 云端收藏、跨端同步、有效投票 | 轻量登录，不要求向其他用户实名 | 昵称化 |
| 提交公开候选内容 | 登录并按上线时适用规则完成后台认证 | 可选昵称或不公开署名 |
| 审核和运营 | 管理账号、多因素认证 | 后台可审计 |

公开页面不展示真实姓名、手机号或认证材料。投稿入口是可选能力，不作为普通用户完成使用流程的障碍；内容供给也不依赖用户愿意投稿。

## 推荐策略的低成本顺序

1. 冷启动：编辑精选 + 领域轮换 + 质量分 + 新鲜度 + 已读去重；
2. 有少量行为后：显式兴趣 + 收藏 + 有用 / 没用 + 继续阅读；
3. 内容量增加后：节点关系和文本相似度召回；
4. 数据足够后：再评估向量召回和更复杂排序；
5. 永远保留跨领域探索位和站长精选位。

不为每次刷新调用大模型。推荐列表由离线或异步任务预计算，公开页优先静态化和缓存。

## 变现顺序

基础常识阅读、来源和纠错能力保持免费。出现真实留存后，按下面顺序小范围验证：

1. 会员增强：跨端同步、深度专题、个性化知识清单、离线包、完整复习与统计；
2. 高价值内容包：经人工审核的专题脉络、时间线、地图和每周背景简报；
3. 受控 AI 能力：只基于已发布内容、带引用，并设置会员额度；
4. 机构服务：企业通识内容、行业知识地图、内部培训与授权接口；
5. 广告或赞助：最后评估，必须清楚标记且不能干预事实排序和审核结论。

不出售用户隐私，不让付费方购买事实结论、审核通过或推荐排名。

## 指标

### 产品北极星

`每周有收获浏览会话数`：一次会话中完成至少 3 条有效阅读，并出现收藏、有用或继续了解中的至少一个行为。它衡量“随手看也真正获得东西”，比搜索量、注册数或单纯 PV 更接近产品目标。

### 无用户也可运行的供给指标

- 各领域核心常识覆盖率；
- 本周新增或完成复核的正式节点数；
- 过期、来源失效和冲突内容的未处理时长；
- AI 候选被人工采用、修改和驳回的比例；
- 站长每审核一条正式内容所需时间；
- 每条正式内容的平均生成与维护成本。

### 商业化触发器

连续四周满足留存、自然回访和内容质量基线后才进入付费实验。具体阈值在公开测试前结合流量规模设定，不在没有数据时写死价格和套餐。

## 修订后的阶段顺序

```text
Phase 1  内容内核、审核与版本闭环
Phase 2  浏览优先的百科网站 + 最小内部供给循环
Phase 3  来源监测、覆盖缺口与 AI 批量审核工作台
Phase 4  浏览优先的微信小程序
Phase 5  个性化、收藏同步与可选学习系统
Phase 6  公开测试、备案、压测与变现验证
Phase 7  带来源 AI 问答（可选、最后）
```

搜索在 Phase 2 只做基础辅助能力，不单独成为产品阶段。最小来源监测和内部候选生成提前到 Phase 2，保证没有用户投稿时百科也能持续增长；Phase 3 再把它做成完整、可观测、低人工负担的运营系统。
