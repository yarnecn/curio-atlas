# 身份、匿名展示与权限基线

## 产品结论

“账号不实名”按当前产品体验解释为：浏览不注册；投稿和评分只注册昵称账号，不要求真实姓名、手机号或邮箱；其他用户只看到昵称。

当前实现用于本地内容建设和封闭测试。公开投稿上线前，需依据届时的主体、功能形态、部署地区和平台规则再次核对实名、备案、内容安全与个人信息要求；不能把“不向公众展示实名”误解为免除运营者的合规义务。

## 身份分层

| 身份层 | 保存内容 | 可见范围 |
|---|---|---|
| 公共资料 | 随机昵称或自选昵称、头像、公开贡献统计 | 所有人 |
| 登录身份 | 当前为昵称账号和密码派生值；以后可增加微信或邮箱映射 | 认证系统 |
| 合规认证 | 仅在上线核对确认确有必要时接入认证结果或凭据 | 严格授权的后台 |
| 风控信号 | 必要的账号、操作、网络与异常行为记录 | 安全与审核人员 |

优先让合规认证由具备能力的第三方或平台完成，业务库只保存认证结果、时间、方式和必要引用标识，不默认保存身份证件影像。最终认证方式需在上线前结合主体、功能和接入平台复核。

## 角色与权限

| 能力 | 访客 | 登录用户 | 投稿者 | 审核者 / 站长 | AI 管理员 |
|---|---:|---:|---:|---:|---:|
| 阅读正式常识 | 是 | 是 | 是 | 是 | 只读 |
| 阅读尝试候选 | 有限 | 是 | 是 | 是 | 只读 |
| 设备内已读和临时兴趣 | 是 | 是 | 是 | 是 | 否 |
| 云端收藏与学习记录 | 否 | 是 | 是 | 是 | 否 |
| 有用 / 没用 | 否 | 是 | 是 | 是 | 否 |
| 提交候选精华 | 否 | 认证后 | 是 | 是 | 仅系统来源草稿 |
| 修改自己的未处理稿 | 否 | 否 | 是 | 是 | 提建议 |
| 公开评论或私信 | 否 | 否 | 否 | 否 | 否 |
| 审核、合并、发布、撤回 | 否 | 否 | 否 | 是 | 否 |
| 调整门槛和来源白名单 | 否 | 否 | 否 | 是 | 只提建议 |
| 执行低风险例行任务 | 否 | 否 | 否 | 是 | 在授权范围内 |

AI 管理员不是一个可登录的人类账号，而是受权限、预算、审计和审批策略限制的系统主体。

## 登录策略

- 浏览不登录；
- 换一条、临时兴趣和设备内已读记录不触发登录；
- 网站当前使用昵称账号和密码，后续可增加微信扫码或邮箱找回；
- 小程序使用微信登录，并由服务端保存身份映射和签发自己的会话；
- 只有云端收藏、跨端进度和有效投票在第一次需要时再触发轻量登录，不因此要求真实姓名；
- 当前封闭测试投稿只要求登录；公网开放投稿前单独完成合规决策，不影响匿名阅读；
- 投稿完成后默认只显示昵称，允许选择不公开署名；后台审核和追责记录仍保留；
- 高风险操作使用二次确认，管理后台使用多因素认证。

## 个人信息最小化

- 每个字段必须有用途、法律基础、保存期限和删除规则；
- 登录标识、合规认证、学习数据、私人笔记和风控日志分开授权；
- 不收集通讯录、精确位置等核心功能不需要的信息；
- 提供隐私规则、注销、导出、更正和删除流程；
- 向 AI 服务商发送内容前删除不必要的个人标识，敏感数据默认不出境；
- 对管理员访问、导出和删除个人信息保留审计记录。

## 上线前身份合规门

- [ ] 依据最终投稿形态确认真实身份认证方案；
- [ ] 完成用户协议、账号规则、隐私政策和投稿规则；
- [ ] 确认认证服务商的数据流、留存和安全责任；
- [ ] 实现账号注销、封禁、申诉和认证状态撤销；
- [ ] 完成最小化检查与个人信息影响评估；
- [ ] 由熟悉互联网信息服务的专业人士复核实际页面和流程。

当前规则依据包括[《互联网用户账号信息管理规定》](https://www.cac.gov.cn/2022-06/26/c_1657868775042841.htm)。法规、备案要求和平台审核规则可能变化，公开投稿上线前必须重新核验，不能把本文当作最终法律意见。
