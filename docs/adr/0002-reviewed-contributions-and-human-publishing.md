# ADR-0002：开放候选贡献与人工正式发布

- 状态：已接受
- 日期：2026-09-03

## 背景

产品希望任何用户都能贡献精华，并用“有用 / 没用”发现有价值的内容；同时即使没有用户投稿，系统也要能根据覆盖缺口和来源变化持续产生编辑候选。正式常识必须简洁、可信、可更新，不能退化为评论社区或票数百科。

## 决策

把候选精华和正式常识建成不同实体与状态机。候选通过 `origin_type` 区分用户投稿、来源发现、覆盖缺口、维护任务和站长种子。用户提交候选，自动检查和 AI 改写通过后进入尝试展示；评分达到可配置门槛只会进入人工审核队列。系统内部编辑候选不依赖公开票数，完成来源和风险检查后直接进入站长审核。审核者可以创建正式节点、合并到已有节点、退回或驳回。

不提供公开评论、回复、私信和自由编辑正式内容。评分只表示用户认为内容是否有用，不表示事实真假。AI 不能发布正式内容。

## 结果

系统需要保存触发来源、投稿原文或来源快照、AI 改写、评分明细、审核结果和正式版本，数据模型与管理后台比纯编辑百科更复杂；换来的好处是既能开放供给、又能在零用户时持续增长，同时不会让热度、争论或模型输出直接污染正式百科。
