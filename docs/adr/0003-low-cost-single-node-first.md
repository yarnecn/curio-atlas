# ADR-0003：低成本单节点生产优先

- 状态：已接受
- 日期：2026-09-03

## 背景

首版流量和留存尚未验证，目标是在有限服务器资源下保证可用性与性能。过早使用微服务、容器编排、独立搜索和多个托管数据库会增加固定成本与运维面。

## 决策

公开测试从可升配的 2 vCPU / 4 GB 级别单节点起步，运行反向代理、Web、API、PostgreSQL、Redis 和低并发 worker。对象文件使用云对象存储，静态资源使用 CDN。正式常识页优先静态化，抓取、AI、索引与导出异步执行。

通过可用性、P95 延迟、CPU、内存、数据库 I/O 和队列积压决定扩容。演进顺序为资源外置、主机升配、数据库独立、worker 独立，再评估服务拆分。

## 结果

首版固定成本和运维复杂度较低，但单机仍是故障域，因此必须有主机外备份、恢复演练、进程守护、监控和降级。生产不使用本地开发用 MinIO。
